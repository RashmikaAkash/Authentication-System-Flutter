# 🔐 Flutter Authentication System using Firebase

This project demonstrates how to implement a **secure authentication system** using **Flutter** and **Firebase**. It includes **Email & OTP verification** to provide a smooth and user-friendly sign-in and sign-up experience.

## 🚀 Features
- **Email & Password Authentication**: Allow users to sign up and log in with their email and password.
- **OTP Verification**: Users can receive a one-time password (OTP) for email verification.
- **Firebase User Management**: Easily manage user authentication and handle different sign-in methods with Firebase.
- **Responsive UI**: Designed to be mobile-friendly and responsive across various screen sizes.
- **Secure and Scalable**: Built with Firebase for a scalable authentication backend.

## 🛠 Tech Stack
- **Flutter (Dart)**: Framework for building the app.
- **Firebase Authentication**: Manages user sign-in, sign-up, and OTP verification.
- **Firebase Firestore**: (Optional) For storing user data if needed.

## 🚀 Getting Started

### Prerequisites
- **Flutter**: Make sure Flutter is installed and set up on your machine.
- **Firebase Project**: Set up a Firebase project in the Firebase Console.

### Steps to Run the Project
1. Clone the repository:
   ```bash
   git clone https://github.com/RashmikaAkash/Authentication-System-Flutter.git
   ```
2. Navigate to the project directory:
   ```bash
   cd your-repo-name
   ```
3. Install dependencies:
   ```bash
   flutter pub get
   ```
4. Set up Firebase in your project by following the steps in the Firebase Console for your app.
   - Add the `google-services.json` to your `android/app` folder (for Android).
   - Follow additional Firebase setup for iOS if applicable.

5. Run the project:
   ```bash
   flutter run
   ```

### Firebase Configuration
- Enable **Email/Password Authentication** and **Email OTP Verification** in the Firebase Console.
- Ensure you've added the required Firebase configuration files to your project.
